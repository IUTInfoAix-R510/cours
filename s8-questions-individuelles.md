## Questions individuelles : 6 minutes, sur votre code

<div class="g2" style="font-size: 0.68em; align-items: stretch;">
<div class="carte vert"><b class="t">Le déroulé</b>

- **6 minutes**, dans votre codespace, avec vos seules connaissances : **ni assistant IA, ni autre aide**
- Toute fonctionnalité que vous avez **écrite ou relue** peut vous être demandée (historique arrêté le mer. 16/12 au soir)
- D'abord **expliquer** (pipeline, service, route, outil), puis **modifier** votre code devant nous

</div>
<div class="carte violet"><b class="t">Ce qui compte</b>

- q = 70 % questions individuelles + 30 % contributions (git, PR écrites et relues)
- Note individuelle = min(100, note d'équipe × (0,6 + 0,5 q))
- Le détecteur d'IA peut mener à un **entretien**, jamais à une pénalité automatique

</div>
<div class="carte"><b class="t">Pendant ce temps</b>

L'équipe continue : quête secondaire, Veillées V1 à V5. Le travail livré après S8 compte pleinement dans la note d'équipe.

</div>
<div class="carte orange"><b class="t">📅 Rendu final</b>

**Dimanche 3 janvier 2027, 23 h 59** : le dernier tag `submit/…` **poussé** avant cette heure est noté ; cinq rendus au plus.

</div>
</div>
